### Bibliotecas de Componentes Externos

### Introdução

Uma biblioteca de componentes disponibiliza elementos de interface reutilizáveis que podem ser incorporados à aplicação.

Esses componentes normalmente já possuem características como:

* aparência visual;
* espaçamento;
* estados de interação;
* comportamentos;
* variações;
* padronização.

Assim, em vez de construirmos todos os elementos da interface a partir de elementos HTML básicos, podemos utilizar componentes fornecidos pela biblioteca.

> **Bibliotecas de componentes mais utilizadas:**
> 
> * Material UI;
> * Ant Design;
> * React Bootstrap;
> * PrimeReact.
