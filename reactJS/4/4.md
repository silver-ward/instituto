### Introdução

No capítulo anterior, utilizamos CSS para definir a apresentação visual dos componentes React.

Para cada componente, criamos uma folha de estilos correspondente:

Label.jsx ─────────────► Label.css  
LabelTitle.jsx ────────► LabelTitle.css  
InputText.jsx ─────────► InputText.css  
InputPassword.jsx ─────► InputPassword.css  
Button.jsx ────────────► Button.css  
Login.jsx ─────────────► Login.css  

Agora utilizaremos outra abordagem para estilizar a mesma aplicação: **Tailwind CSS.**

Com Tailwind, grande parte da estilização pode ser realizada diretamente no JSX utilizando classes utilitárias.

Por exemplo, anteriormente poderíamos ter:
```
<button className="btn">
  Logar
</button>
```

e definir sua aparência em outro arquivo:

```
.btn {
  width: 100%;
  padding: 0.8rem;
  background-color: #0066cc;
  color: white;
}
```

Com Tailwind, essas características podem ser representadas diretamente no elemento:

```
<button className="w-full px-4 py-2 bg-blue-600 text-white">
  Logar
</button>
```

> **Tailwind CSS**
>
> Tailwind utiliza uma abordagem conhecida como Utility-First CSS.
>
> Em vez de criarmos uma classe CSS personalizada para cada elemento, combinamos classes utilitárias que representam propriedades específicas de estilo.
